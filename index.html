About

Who's building this

I'm Stefan. I build software that runs on hardware I actually own — usually late in the evening, with more terminal tabs open than I'd like to admit.

Local-first isn't really a philosophy for me so much as a preference: I'd rather host something myself and understand exactly how it works than hand it to someone else's server. SAMIDA is where that preference gets applied most literally — everything else on this page shares the same instinct.

Right now
  • Running SAMIDA on an always-on Ubuntu box, reachable only over Tailscale
  • Building Pirate Survival's archipelago in Unreal Engine
  • Keeping PinguHub's dozen-odd services alive
