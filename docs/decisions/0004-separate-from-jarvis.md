# Beslut 0004: SAMIDA är separat från Jarvis

- Status: accepterat
- Datum: 2026-09-08

## Beslut

SAMIDA är ett fristående projekt. Det ska inte ersätta Jarvis eller Jarvis Web
och ska inte byggas som deras nya frontend eller backend.

## Konsekvenser

- SAMIDA har egen katalog, arkitektur, identitet, konfiguration och lagring.
- Ingen kod eller tjänst delas automatiskt med Jarvis-projekten.
- SAMIDA får känna till Jarvis och Jarvis Web som aktiva användarprojekt och
  hjälpa till med dem inom separat beviljade behörigheter.
- En framtida integration mellan projekten kräver ett separat uttryckligt beslut.
