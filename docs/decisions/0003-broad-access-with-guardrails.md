# Beslut 0003: Bred åtkomst med skyddsräcken

- Status: accepterat som målbild
- Datum: 2026-09-08

## Beslut

SAMIDA ska när systemet är moget kunna hjälpa till brett på den lokala datorn,
inklusive Unreal-projekt, webbprojekt, PowerShell och webbläsare. Kapabiliteten
ska levereras via separata verktyg med begränsningar, riskklassning, loggning och
bekräftelser. Modellen får inte direkt obegränsad datoråtkomst.

En särskild Gmail och fler produktivitetsverktyg ska utvärderas genom gemensam
diskussion innan de ansluts.
