# Beslut 0007: React-baserat lokalt webbgränssnitt

- Status: accepterat
- Datum: 2026-09-08

## Beslut

SAMIDAs webbgränssnitt byggs med React och TypeScript på en Vite-baserad
Vinext-grund. Webbappen körs lokalt och anropar FastAPI-backenden.

## Första gränssnittet

- Chatt är den primära arbetsytan.
- Ollama- och modellstatus visas tydligt.
- De kontextfiler som används för ett svar redovisas.
- Minne och behörigheter får egna vyer först när funktionerna implementeras.
